# BreakBite

A smart canteen web project for the Gono Bishwabidyalay CSE Software Development Contest 2026 (Category 1: Semester 1st to 4th).

## About

BreakBite helps students spend less time waiting in the university canteen. Students can see the menu, order ahead, get a token and know the waiting time. Staff can manage orders and food from their own page.

## Features

- Digital Menu
- Token System
- Waiting Time
- Pre-order
- Rush Radar
- Break Planner
- Green Token
- Food Waste Saver
